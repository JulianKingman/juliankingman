# juliankingman.com

Personal portfolio site. Next.js (App Router) + Tailwind v4.

- Solo project with a single editor: commit and push straight to `main`, which deploys the site. No feature branches or pull requests unless asked.
- Checks before pushing: `npx tsc --noEmit` and `npm run build`.
- Look: amber phosphor CRT on warm near-black, pixel art. Keep colours in the amber family. Buttons use the `.btn-crt` classes in `src/app/globals.css`.
